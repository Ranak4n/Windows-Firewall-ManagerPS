# Windows Firewall Manager (PowerShell)

Outil interactif en PowerShell pour gérer les règles du pare-feu Windows :
blocage entrant/sortant de programmes, en ligne de commande, sans passer par
`wf.msc`.

## Statut

🚧 Reprise d'un projet perso — en cours de remise à plat.

## Prérequis

- Windows 11
- PowerShell 7+ (testé sur 7.6) — module `NetSecurity` fourni par Windows
- **Session élévée (Administrateur)** : toute modification de règle l'exige
